# Security Policy

## Supported Versions

Only the latest release of ASCIIstuff (`asciistuff` on [PyPI](https://pypi.org/project/asciistuff/)) receives security fixes.

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub issues.

Instead, report them privately through [GitHub's private vulnerability reporting](https://github.com/dhondta/python-asciistuff/security/advisories/new) (the repository's *Security* tab, then *Report a vulnerability*). Please include:

- the ASCIIstuff version and Python version;
- the steps to reproduce the issue;
- the impact you expect.

You will get an answer as soon as possible. Once the issue is confirmed, a fix is released and the advisory is published.
